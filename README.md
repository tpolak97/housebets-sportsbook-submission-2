# Housebets Sportsbook — Submission 2 · Classic

Clickable, front-end-only contest prototype. All odds, stakes, results, and bets are simulated. Player names are fictional.

## Five contest views

1. [Sports home](fieldbook/#6/home/0)
2. [Live](fieldbook/#6/live/0)
3. [Football](fieldbook/#6/football/0)
4. [Match page](fieldbook/#6/match/0)
5. Bet slip + My bets: tap odds to open the slip, then visit [My bets](fieldbook/#6/bets/0).

Works at 390px phone width and 1440px desktop width. No login required.
